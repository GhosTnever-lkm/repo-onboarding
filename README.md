# Repository Onboarding

> Understand an unfamiliar codebase quickly with a structured, evidence-backed walkthrough.

## Install

In Codex, add the [GhosTnever Codex Toolkit](https://github.com/GhosTnever-lkm/ghosTnever-codex-toolkit) marketplace, then install **Repository Onboarding**.

You can also clone this repository and add it as a local marketplace:

```text
codex plugin marketplace add .\path\to\ghosTnever-codex-toolkit
codex plugin add repo-onboarding --marketplace ghosTnever-codex-toolkit
```

## Try it

- "Give me a quick tour of this repository."
- "Where is the authentication flow implemented?"
- "What is the safest first issue to pick up?"

## Scope

This plugin contains a focused Codex skill. It does not install external services or run background processes. Review repository guidance and user authorization before taking actions.
